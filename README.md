Entry for the make.fun competition **The 3AM Fridge Text** — the one line a smart
fridge texts its owner at 3am.

## The line

> You've opened me 14 times since midnight and eaten nothing. Therapy is cheaper than my electricity bill.

The fridge has been awake all night counting, and it has decided 3am is the
moment to speak: no milk, no ice, no door left open — just an appliance with
an opinion and an electricity bill, landing the punch on the last words.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set), validated against the gate: UTF-8, 1–140 characters, a single line,
not whitespace-only. Python standard library only, deterministic, no network.
